# SURDZ

SURDZ is a free visual workspace for Windows: boards, cards, drawing and templates for ideas, designs, lessons and projects. It works offline.

## Download

Download **[SURDZ-Setup.exe](https://github.com/decostar27/surd-releases/releases/latest/download/SURDZ-Setup.exe)**, then run it. Installed copies of SURDZ update themselves when a new version is released.

This repository holds the installer and update files only.

Website: https://surdz.vercel.app
